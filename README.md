# MUJI自動チェックイン（Android）

無印良品の店舗に近づくと、MUJIアプリ（MUJI passport）を自動で開いて「チェックイン」ボタンを押し、元の画面に戻るアプリです。

## 仕組み
- **自動タップ**: ユーザー補助サービス（`CheckinAccessibilityService`）がMUJIアプリの画面を読み、ホーム画面の帯「チェックイン」→ 店舗一覧の `id/check_in` の順に押します。画面の流れは [docs/checkin-flow.md](docs/checkin-flow.md) を参照してください。
- **店舗検知**: 登録した店舗をジオフェンス（半径150m）に登録しておき、近づいたら `GeofenceReceiver` → `requestAutoCheckin()` が動きます。
  - 画面ロック中は待機し、ロックを解除した時点で実行します。
- **店舗の学習**: チェックインに成功した場所を、店舗として自動で登録します。最初の1回だけ自分でMUJIアプリを開けば（自動タップは働きます）、次回からは近づくだけで自動チェックインします。
- 店舗ごとに「今日チェックインしたか」を記録します。近づいた店舗がすべて今日チェックイン済みなら、MUJIアプリは開きません。1店舗でも未チェックインの店舗があれば開いて、一覧に出ている店舗をすべてチェックインします。
- 自分でボタンを押した店舗も、店舗一覧で「チェックイン済み」と表示されていれば記録に反映します。
- **確認モード**: 自動でMUJIアプリを開く代わりに「チェックインしますか？」という通知を出します。通知のボタンを押すと、自動で開いてタップし、元の画面に戻ります。店舗から離れると通知は消えます。

## ビルドとインストール
```bash
./gradlew assembleDebug
```
```bash
adb install -r app/build/outputs/apk/debug/app-debug.apk
```

## 初期設定（端末で行う）
1. 位置情報 →「常に許可」
2. 通知を許可
3. 設定 > ユーザー補助 > インストール済みアプリ > 「MUJI自動チェックイン」をON
   - ONにできない場合: アプリ情報 > ︙ > 「制限付き設定を許可」
4. Galaxyの場合: アプリ情報 > バッテリー >「制限なし」にすると、ジオフェンスが止まりにくくなります

## デバッグ（debugビルドのみ）
店舗への進入を擬似的に発生させます（`force true` を付けると、今日チェックイン済みでも実行します）。
```bash
adb shell am broadcast -a io.github.mujicheckin.DEBUG_ENTER -n io.github.mujicheckin/.DebugTriggerReceiver --ez force true
```
ログの確認:
```bash
adb logcat -s MujiCheckin
```

## 制約
- 実行のたびにMUJIアプリが一瞬（数秒）前面に表示されます。
- MUJIアプリの画面構成（リソースID）が変わると動かなくなります。
- ジオフェンスの検知は、最大で数分遅れることがあります。
